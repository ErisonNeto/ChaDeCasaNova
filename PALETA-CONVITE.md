# Paleta aplicada — Convite Virtual Jeyse & Erison

Paleta inspirada no PDF do convite do Chá de Casa Nova, usando fundo perolado, rosé queimado, concha rosada e dourado champagne.

| Uso | Cor | Hex |
|---|---:|---|
| Fundo principal perolado | Pearl / Champagne | `#F7EEE9` |
| Cards e áreas claras | Porcelain | `#FFF8F5` |
| Texto principal | Cocoa | `#6D5148` |
| Destaque rosé | Rose | `#B96F68` |
| Botões principais | Rose Deep | `#8E514B` |
| Dourado champagne | Gold | `#D8A56E` |
| Concha rosada | Shell | `#F6C7B9` |
| Blush suave | Blush | `#F3D6D0` |
| Linho / bordas | Linen | `#EFE2DC` |
